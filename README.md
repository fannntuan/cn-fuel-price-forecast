# 国内成品油调价预测 · cn-fuel-price-forecast

> 按发改委的 10 个工作日调价机制，用国际原油行情自己算出「下一轮油价涨还是跌、多少、哪天」。
> 单文件、零第三方依赖、国内网络直连可用。

```
$ python3 fuel_forecast.py
【国内成品油调价预测】2026-11-13 14:02
上次调价：2026-11-12  （模型估算 -486 元/吨，官方未确认）
下个窗口：2026-11-26 24时（自算）
本周期（2026-11-12 ~ 2026-11-25）进度 2/10，布伦特/WTI 估算均价 91.93 美元
  已发生 2 个工作日均价 92.10，剩余 8 天按现价 91.89 延续估算
上周期（2026-10-29 ~ 2026-11-11）均价 96.47 美元
变化：-4.54 美元/桶（-4.71%）
→ 预测下调：-266 元/吨，折合 92 号汽油 -0.213 元/升
  置信度：低
实时行情：布伦特 95.68  WTI纽约 88.26
⚠ 数据源冲突：站点记 2026-10-29 为 -345 元/吨，模型按同期原油行情还原为 +430 元/吨，方向相反。
  → 本轮预测仅供参考，请人工核对（站点文案陈旧或原油数据异常）
```

## 它是怎么算的

《石油价格管理办法》：汽柴油最高零售价**每 10 个工作日**调整一次，挂靠国际市场原油价格。

```
本周期均价 = 窗口前 10 个工作日     布伦特/WTI 等权均价
上周期均价 = 再往前 10 个工作日     均价
ΔP         = 本周期均价 − 上周期均价            （美元/桶）
汽油吨价变动 = K × ΔP                          （元/吨）
|变动| ≥ 50 元/吨 → 调价；< 50 → 搁浅（金额累加到下轮）
元/升       = 元/吨 ÷ 1250                     （92# 零售端实际折算）
```

`K` **不是拍出来的**，是拿官方历史调价记录回归出来的，当前值 **58.56 元/吨 每 1 美元/桶**。
`--verify` 会重跑回归——机制或数据口径变了，以回测值为准。

几个容易搞错的细节：

- **折算系数用 1250 而不是理论 1388**：官方挂牌价实测 `345 元/吨 ↔ 0.27~0.28 元/升`、`90 元/吨 ↔ 0.07~0.08 元/升`，反推约 1250 L/吨。
- **窗口没走完时不能用「未来工作日」**：10 个工作日里如果有一半在今天之后，直接取数会拿最新价占位、算出假均价。正确做法是只统计已发生的工作日，剩余按现价延续估算，并标注进度（`2/10`）和置信度。
- **工作日必须用真实节假日**：只按「周一到周五」会在国庆/春节把窗口算偏。

## 数据源

| 用途 | 源 | 备注 |
| --- | --- | --- |
| 原油实时 + 历史日线 | `hq.sinajs.cn` · `stock2.finance.sina.com.cn` | `hf_OIL`=布伦特、`hf_CL`=WTI，日线自 2016 年 |

| 工作日/节假日 | `chinese_calendar`（pip） | 缺省退化为工作日=周一到周五 |

## 接进自己的日报 / 通知

```bash
# cron：每天跑，非触发日静默（0 网络、0 输出）
OUT=$(python3 /path/fuel_forecast.py --snippet)
[ -n "$OUT" ] && printf '%s\n' "$OUT" | 你的推送命令
```

`--snippet` 的触发点是「距窗口还剩 5 个工作日」（周期中点）和「还剩 1 个工作日」（前一天），
状态存在缓存目录的 `snippet_state.json`，不用自己维护。

## 踩过的坑

- 汽油价格网 **https 打不开**（`http=000`），`/tz/` 目录页 403，但具体年份页 200。
- 该站的「今日…是 X 月 X 日 24 时…后的价格」**可能停在上上轮**，而「下次调整将在 X 日」已经过去了 → 
  窗口日期 ≤ 今天时，程序会判定该轮已落地、幅度记「官方未确认」并给模型估算，**不照抄站点文案**。
- 官方挂靠油种（布伦特/迪拜/阿曼）和权重未公开，本工具用布伦特+WTI 等权近似。
- 未建模汇率与「40 美元地板价 / 130 美元天花板」调控，极端行情下偏差会放大。
